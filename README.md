# 📊 Channel Graph — Telegram Mini App (TMA) & Bot

> Профессиональный сервис визуализированной аналитики Telegram-каналов, генерации PDF/PNG медиакитов для рекламодателей и монетизации через Telegram Stars.

Бот в Telegram: **[@StatVisualBot](https://t.me/StatVisualBot)**

---

## 🚀 Основные возможности сервиса

1. **📈 Интерактивный дашборд аналитики:**
   - Динамика роста аудитории (прирост, отток, чистый прирост).
   - Распределение просмотров по дням и 24-часовая тепловая карта активности аудитории.
   - Расчет метрик вовлеченности: **ERR (Engagement Rate)**, средний охват 1 поста, индекс цитирования (ИЦ).
   - Топ недавних публикаций канала с прямыми ссылками и откликом аудитории.

2. **🔍 Поиск и анализ любого публичного канала:**
   - Введите `@username` любого канала (например, `@telegram`, `@durov`) прямо в приложении или отправьте в чат с ботом.
   - Сервис в реальном времени получает количество подписчиков, официальный HD-аватар и строит аналитический срез.

3. **🤖 Автоматическое подключение каналов:**
   - При добавлении `@StatVisualBot` администратором в ваш канал бот автоматически сохраняет его в базе данных и отправляет уведомление со ссылкой на дашборд.

4. **📑 Профессиональный PDF-медиакит для рекламодателей:**
   - Включает настраиваемый прайс-лист (форматы **1/24**, **2/48**, **Натив**).
   - Портрет аудитории (пол, гео, возраст) и расчетный CPM.
   - Кликабельные гиперссылки для прямого перехода к менеджеру канала (`t.me/username`).
   - 100% векторный рендеринг без обрезок с поддержкой кириллицы.

5. **🖼 Компактные PNG-инфографики (1:1 Social Cards):**
   - Квадратный формат (1280×1280 HD) для быстрой публикации в Telegram-каналах и чатах без прокрутки.

6. **🤖 AI Смарт-Аналитика (Smart Insights):**
   - **Time-to-Post Optimizer:** определение лучшего времени публикации постов для максимального охвата.
   - **Индекс виральности контента (Virality Score):** оценка готовности аудитории делиться постами.
   - **Рекомендованный прайс рекламы:** автоматический расчет справедливой рыночной стоимости постов.

7. **⭐ Монетизация через Telegram Stars & AdsGram:**
   - Оплата тарифов **PRO** через нативный платежный интерфейс Telegram Stars (`XTR`).
   - Разблокировка годовой аналитики (`1 Год PRO`) и безлимитного экспорта без рекламы.
   - AdsGram Rewarded Ads для бесплатных пользователей.

## 🛠 Технологический стек

- **Frontend:** React 18, TypeScript, Tailwind CSS, Vite 6, Chart.js, React-ChartJS-2, jsPDF, html2canvas, Lucide Icons, Canvas Confetti.
- **Backend:** Node.js, Express, TypeScript, grammY (Telegram Bot API 8.0+), GramJS (MTProto), Axios.
- **Безопасность:** Валидация HMAC-SHA256 подписи `initData` Telegram WebApp.

## ⚙️ Установка и запуск

### 1. Клонирование и установка зависимостей
```bash
git clone <repo-url>
cd TelegramProject

# Установка зависимостей бэкенда и фронтенда
npm run install:all
```

### 2. Настройка переменных окружения
В файле `backend/.env`:
```env

FRONTEND_URL=https://your-domain.com

```

### 3. Локальный запуск
```bash
# Запуск бэкенда (порт 3001)
npm --prefix backend run dev

# Запуск фронтенда (порт 3000)
npm --prefix frontend run dev
```

## 📱 Настройка в @BotFather

1. Откройте **[@BotFather](https://t.me/BotFather)** в Telegram.
2. Введите команду `/mybots` ➔ выберите `@StatVisualBot`.
3. Перейдите в **Bot Settings** ➔ **Menu Button** ➔ **Configure menu button**.
4. Введите URL вашего продакшн-домена (например, `https://your-domain.com` или Cloudflare URL).
5. Введите название кнопки: **«📊 Statify»**.
